## Commits
This repo uses Conventional Commits v1.0.0. PRs are squash-merged with the PR title as the whole commit message; the description stays on the PR. CI checks the title with commitlint. Breaking changes are signaled only with `!` in the title, never a footer.
Plan work as one logical change per PR. Use the `conventional-commits` skill when writing commit messages, PR titles, or PR descriptions.
